# 오늘의 찬장 — 깃허브에 올려서 진짜 웹앱으로 쓰기

이 폴더에 있는 파일들을 깃허브에 올리면, 더 이상 html 파일을 따로 들고 다니거나
실수로 지울 일 없이 **링크 하나로 언제든 접속**할 수 있고, 폰 홈 화면에 아이콘으로도
추가할 수 있어요.

## 폴더 구성
```
index.html          ← 앱 본체
manifest.json        ← 홈 화면 추가 시 아이콘/이름 설정
service-worker.js     ← 오프라인에서도 열리게 해주는 파일
icons/
  icon-192.png
  icon-512.png
  apple-touch-icon.png
  favicon-32.png
  favicon-16.png
```

## 1. 깃허브에 올리기 (폰 브라우저에서도 가능)

1. [github.com](https://github.com) 접속 → 로그인 (계정 없으면 가입)
2. 오른쪽 위 **+** 버튼 → **New repository**
3. Repository name에 `banchan-planner` 같은 이름 입력 (영문) → **Public** 선택 → **Create repository**
4. 저장소 페이지에서 **Add file → Upload files** 클릭
5. 이 폴더 안의 파일들을 **폴더 구조 그대로** 끌어다 놓기 (또는 선택해서 업로드)
   - `icons` 폴더째로 끌어놓으면 안에 있는 파일들도 그대로 경로 유지되면서 올라가요
   - 폰에서 업로드할 땐 파일 선택 창에서 폴더 안 파일들을 한 번에 여러 개 선택하면 돼요
6. 아래 **Commit changes** 클릭해서 저장

## 2. 깃허브 페이지(무료 호스팅) 켜기

1. 저장소 메뉴에서 **Settings** 클릭
2. 왼쪽 메뉴에서 **Pages** 클릭
3. **Build and deployment → Source**를 **Deploy from a branch**로 설정
4. **Branch**를 `main` / `/ (root)`로 선택 → **Save**
5. 1~2분 기다리면 상단에 **"Your site is live at https://(아이디).github.io/banchan-planner/"** 같은 주소가 떠요

## 3. 폰 홈 화면에 추가하기

위에서 생긴 주소로 폰 브라우저에서 접속한 다음:

- **안드로이드(크롬)**: 주소창 옆 점 3개 메뉴 → **홈 화면에 추가** (또는 하단에 자동으로 뜨는 설치 배너)
- **아이폰(사파리)**: 공유 버튼(□↑) → **홈 화면에 추가**

이렇게 하면 폰 홈 화면에 반찬 그릇 모양 아이콘이 생기고, 탭 한 번으로 앱처럼 바로 열려요.
데이터는 접속하는 브라우저 기기에 저장되는 방식이라, 등록했던 반찬 데이터는 그대로 유지됩니다
(단, 브라우저 저장공간을 지우면 사라질 수 있어요).

## 나중에 기능을 수정하고 싶으면

`index.html` 파일을 고친 다음, 같은 저장소에서 **Add file → Upload files**로 같은 파일명으로
다시 올리면 자동으로 덮어쓰기(업데이트)돼요. 몇 분 뒤 같은 주소에서 바로 반영됩니다.
